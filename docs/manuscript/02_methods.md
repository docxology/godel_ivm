# Methods

The coordinate interface selects the tetrahedron at frequency one.
The local check reads its points, computes their centroid, and measures
each unordered pair of points with the Euclidean norm. The native
plotting command renders the same selected shape with Matplotlib
[@hunter]. The replay then decodes the saved PNG and records the
measured counts and rounded lengths.

The [reproduction guide](https://github.com/docxology/godel_ivm/blob/main/docs/reproduce.md)
contains the exact commands and output locations.
