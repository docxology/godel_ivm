# IVM Polyhedron Visualization System

A Python toolkit for inspecting polyhedron coordinates and generating
static plots, animations, and interactive geometry views. The project
implements coordinate material credited to Noel Coughlin and uses the
Isotropic Vector Matrix as its geometric context.
